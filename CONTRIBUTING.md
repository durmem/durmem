# Contributing

Thanks for helping improve Durmem. Bug reports, setup problems and documentation
feedback are welcome in this repository's
[Issues tab](https://github.com/durmem/durmem/issues).

You may also open a pull request to propose a documentation or example change.
Keep reports and examples free of credentials, account details and customer
data; for a software issue, open an issue using the Support form instead.

A pull request is a proposal, not a direct change to this distribution.
Maintainers review accepted changes, verify them, and include them in a later
release. Please do not merge into this repository directly.

By participating you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).

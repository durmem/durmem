# Tutorials

<!-- loom-doc: slug=tutorials; audience=both; section=tutorials -->
Use these tutorials to practice saving, connecting, and acting on project memories. Read
[What is Durmem](../guide/what-is-durmem.md) for the basic concepts, then complete
[Quickstart](../guide/quickstart.md). The examples use the
`palmerpenguins` repository and `[demo]` store, and explain how to adapt their outcomes to your own
project.

## Core project-memory path

1. [Durmem data types for coding agents](data-types-for-coding-agents.md): save different kinds of
   knowledge and connect related facts.
2. [Give agents real-time reminders](give-agents-real-time-reminders.md): bring saved instructions
   back when an agent needs them, including at the start of a new session.
3. [Manage a project](manage-a-project.md): organize a plan, ask the agent to carry it out and
   review the results.

## Advanced

- [Track values that change](changing-prices.md): record synthetic values and check their history.
- [Turn repeated work into a server-side function](reuse-a-question.md): test a reusable calculation against its source
  after the core path.

These examples are optional; each lists its own prerequisites.

## Kanban: coordinate agents and computers

Read these in order, or go directly to the operation you need. Kanban exercises use `[kanban]`.

1. [Kanban: coordinating complex work](../kanban/what-is-kanban.md): understand the roles and durable records.
2. [Manage Kanban fleet](../kanban/connect-computers.md): connect computers, start workers and run your first KanbanTask.
3. [Build a beak length report with a Kanban fleet](../kanban/penguin-walkthrough.md): drive design, cross-harness reviews, implementation, tests and reporting with two coordinator prompts.
4. [Tour the Kanban page](../kanban/kanban-board-tour.md): read status and find the next action.
5. [Keep Kanban work safe with the Vault](../kanban/trust-and-vault.md): install the shared key and assign secret profiles.
6. [Maintain and troubleshoot Kanban](../kanban/maintain-workers.md): adjust the fleet and ask the coordinator to resolve stalled work.
